# CustomVinaEditor

这是在线编辑器的独立运行版本，保留界面、解析与渲染模块、Pogget 标准数据、打开示例所需的预设，以及本地 FA6 图标、字体和许可证。

本地预览需要 Node.js 20 或更新版本，无需安装依赖。在本目录运行：

```powershell
npm start
```

打开 <http://127.0.0.1:4173>。若端口已占用，可在 PowerShell 中先设置 `$env:PORT=4174`，然后运行 `npm start`，打开对应端口。

也可以把此目录作为网站根目录部署到静态 HTTP 服务。请保留目录结构；浏览器模块与预设读取需要 HTTP 服务。

FA6 图标及字体由 Fonticons, Inc. 提供，许可证见 [vendor/fontawesome/LICENSE.txt](vendor/fontawesome/LICENSE.txt)。

点击顶部带光标图标的 **行为节点**，在大弹窗中编辑交互。按组件查看现有行为，也可搜索属性、添加节点、拖动端口或依次点击两个端口连线。蓝色线传递数据，虚线传递事件；选择节点编辑路径、默认值和表达式，选择连线或节点后按 Delete 删除。滚轮缩放，中键或空格拖动画布，F 适应画布，双击节点以 100% 缩放定位。弹窗内支持 Ctrl+Z / Ctrl+Shift+Z 撤销重做。

“点击展开示例”会为当前组件创建完整的点击事件 → 布尔状态切换 → 条件表达式 → 宽度绑定。也可导入 [BehaviorDisclosure.vina](examples/BehaviorDisclosure.vina) 体验点击保持展开和悬停外观。表达式使用 `${a}`、`${b}`、`${c}` 接收连线输入，支持 Vina 的算术、比较、逻辑、条件与函数，也可直接引用完整变量路径。状态节点写入 `Component.state`；属性节点可绑定 `width`、`visible`、`label`、`hover`、`hoverRegion` 和动画属性等完整路径。

点击 **检查行为** 校验，点击 **应用行为** 写入工程，再点击编辑器的 **运行** 测试。应用是一次可撤销的工程事务；关闭未应用的修改需要再次确认放弃。无效连线、循环、重复属性写入和非法状态不会替换工程。运行时非法状态更新会回滚，长按动作不会触发短按状态切换，移出组件或失焦会取消点击。

行为使用原生 CustomVina 的 `state`、`toggle`、`action`、`holdAction`、悬停和属性表达式，不执行 JavaScript。每个组件支持一个短按状态切换和一个短按动作，以及一个长按动作；宿主动作在 Pogget 中执行。编辑继承行为只生成当前工程的覆盖；基础预设中的 `toggle` 若需删除，须先导出独立预设再导入编辑。导出 `.vina` 包含实际交互语法，重新导入时重建连线；工程 JSON 和本地自动保存同时保留节点布局和未连接的节点。

运行 `npm test` 执行模型和导入回归。设置 `CHROME_PATH` 为 Chromium / Edge 的可执行文件路径后，同一命令还会验证真实浏览器连线、弹窗校验、预览点击、保存重载及浅深色和窄屏布局。
